# Operator UI screenshots

Each PNG is generated by the corresponding `scripts/ui/*.mjs` check. Web views use 1440 by 900; terminal views capture a 140 by 42 private tmux pane. All views are dark. Task 2 has two harness smoke images; Tasks 7–15 and 17–23 each have initial, progress, success and error states. Backend Tasks 1, 3–6 and 16 have no UI states.

Task 23 runs both clients against one disposable hub. Its assertions verify cross-client approval, read and presence synchronization, both presence heartbeats, wake delivery, expiry history and rejection of a browser credential. The success image captures the expiry step after synchronization and both heartbeats pass. See [the guide](../../../OPERATOR.md#reconnect-and-credential-changes).

Message bodies, timing and priority tips (issues 21, 23 and 25) come from `scripts/ui/md-thread.mjs`. Bodies render as a safe markdown subset; each header shows the gap since the previous message beside its time and a live relative time beside reply; the priority buttons explain themselves on hover and keyboard focus. Desktop is 1440 by 900; narrow is 390 by 844.
